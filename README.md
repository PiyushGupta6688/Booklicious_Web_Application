# 📚 Booklicious — Online Bookstore Platform

**Booklicious** is a full-stack web application designed for **buying, managing, and browsing books** online.  
It features a dynamic **admin dashboard**, **secure cart system**, and **smooth UI** built using **Spring MVC**, **JSP**, and **MySQL**.  
The platform ensures responsive navigation and efficient user management for both admins and customers. 💡  

💻 **Source Code:** [GitHub Repository](https://github.com/PiyushGupta6688/Booklicious_Web_Application)

---

## ✨ Features

- 🛍️ **Book Catalog Management:** View, add, and manage books through the admin dashboard  
- 🛒 **Shopping Cart System:** Add/remove books and proceed to checkout with real-time updates  
- 🔐 **User Authentication:** Secure login and registration  
- 💾 **Persistent Data Storage:** MySQL database integration for seamless data management  
- 💻 **Admin Dashboard:** Manage books, orders, and users from a single interface  
- 🌈 **Responsive UI:** JSP + Bootstrap-based front-end for smooth navigation across devices  
- ⚡ **Optimized REST APIs:** Built for fast, scalable communication between front and backend
